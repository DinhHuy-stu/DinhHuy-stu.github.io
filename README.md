# Nguyen Dinh Huy - Online Resume / CV

[![Live Demo](https://img.shields.io/badge/Demo-Live%20Resume-261758?style=for-the-badge&logo=github)](https://dinhhuy-stu.github.io/)

A modern, clean, and responsive professional CV / Resume website tailored for Nguyen Dinh Huy, built with pure semantic HTML5 and modern CSS3.

🌐 **Live URL:** [https://dinhhuy-stu.github.io/](https://dinhhuy-stu.github.io/)

---

## 📌 Features

- **Standard A4 Layout:** Optimized for both desktop/mobile screens and standard A4 printing (`794px × 1123px`).
- **One-Click Export / Print:** Built-in floating print button that triggers browser print/PDF export cleanly without UI clutter.
- **Modern Aesthetics:** Harmonious dark purple primary theme (`#261758`), typography powered by Google Fonts (`Plus Jakarta Sans`), and a circular profile avatar.
- **Fast & Lightweight:** Pure HTML & CSS with zero heavy dependencies or external runtimes.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure, accessible links, and SVG icons.
- **CSS3:** Flexbox, CSS Grid, custom CSS variables, and `@media print` rules.
- **Hosting:** GitHub Pages.

---

## 🚀 Local Development

You can run this project locally using Python's built-in HTTP server or any live server:

```bash
# Using Python 3
python3 -m http.server 8080
```

Then visit: [http://localhost:8080](http://localhost:8080)

Or simply open `index.html` in your favorite web browser.
